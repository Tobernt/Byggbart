00:00–00:25 · Visa helheten

Vad är sidan till för?

”Det här är Byggbart, en fiktiv konferens om backend och systemdesign. Besökaren kan läsa fem programpunkter, möta fem talare, jämföra tre biljetter och hitta praktisk information. Temat knyter an till mitt intresse för systemutveckling.”

00:25–01:00 · Dra i webbläsarfönstret

Visa desktop, tablet och mobil.

”Jag använder Flexbox för menyn och CSS Grid för talarna. På stora skärmar visas tre talarkort bredvid varandra, sedan två och sist ett. Programmet får tiden ovanför texten i mobilvy. Samma innehåll finns kvar utan horisontell scroll.”

Gör: dra från brett fönster till ungefär 768 och 320 px. Öppna mobilmenyn och hoppa till Talare.

01:00–01:40 · Mus och tangentbord

Förklara hover-effekten.

”Ett talarkort visar mer information och får färg när jag håller musen över det. Med Tab får länken fokus och :focus-within ger samma effekt. Därför är extrainformationen inte beroende av en mus.” 

.speaker-card:is(:hover, :focus-within)
  .speaker-card__details {
  grid-template-rows: 1fr;
}

01:40–02:20 · Visa CSS-källan

Tre avancerade selektorer.

”Syskonselektorn ger en linje mellan programpunkterna. :nth-child(even) gör varannan rad lättare att följa. Biljettens data-attribut väljer vilket kort som markeras, och ::before skapar etiketten. Jag har skrivit egna BEM-klasser i Tailwinds komponentlager.” 

.programme__item + .programme__item { border-top: …; }
.programme__item:nth-child(even) { background: …; }
.ticket-card[data-featured='true']::before { content: …; }

02:20–03:00 · Tema och tillgänglighet

Avsluta med medvetna val.

”CSS-variabler styr färgerna och prefers-color-scheme följer systemets tema. Knappen låter användaren välja själv. Introduktionens CSS-animation stängs av med prefers-reduced-motion. Jag har också lagt till en hoppa-till-innehållet-länk, synlig tangentbordsfokus och korrekta bildattribut.”

Gör: växla tema. Säg sedan: ”Det viktigaste jag tar med mig är att responsivitet och tillgänglighet behöver planeras tillsammans.”

Vanliga följdfrågor att öva på
  • Grid för två dimensioner; Flexbox för en rad som kan brytas.
  • + väljer nästa intilliggande syskon, inte alla efterföljande element.
  • :focus-within gäller föräldern när ett barn får fokus.
  • ::before är en visuell etikett. Biljettens viktiga innehåll finns i HTML.
  • CSS fungerar även utan JavaScript. Temat följer då systemet och navigeringen visas utan menyknapp.
  • Att AI hjälpt till med koden ersätter inte att kunna förklara koden själv.
Om läraren frågar om portfolion

Portfolion är en separat uppgift. Den visar min profil inom backend och automation, fyra projekt, erfarenhet och ett kontaktformulär som förbereder ett mejlutkast. Den lokala länken ovan öppnar den i samma server när portfolio-mappen finns bredvid konferensprojektet.
