# Konferensuppgiften — innehåll och verifiering

Källa: [BCU26D, inlämningsuppgift 2](https://postmodernistx.github.io/bcu26d-musical-octo-disco/examination/03-inl-2.html).

| Krav                                   | Implementation                                                     |
| -------------------------------------- | ------------------------------------------------------------------ |
| Minst fem programpunkter               | `#program`: fem tider, titlar, talare och beskrivningar            |
| Minst fem talare                       | `#talare`: fem illustrerade talarkort                              |
| Minst tre biljettnivåer                | `#biljetter`: Student, Utvecklare och Team                         |
| Praktisk information och statisk karta | `#praktiskt`: adress, tider, mat, tillgänglighet och SVG-karta     |
| Ramverk och egna selektorer            | Tailwind, med BEM-klasser i `@layer components`                    |
| Avancerade selektorer                  | `+`, `:nth-child`, `:focus-within`, attributselektorer, `::before` |
| Animation och reducerad rörelse        | `arrive` och `prefers-reduced-motion`                              |
| Ljust/mörkt tema                       | CSS-variabler, `prefers-color-scheme` och temaknapp                |
| Hover med tangentbordsmotsvarighet     | Talarkortens `:hover` och `:focus-within`                          |
| Responsivitet                          | Kontroller vid 320, 768, 1024 och 1440 px i båda teman             |
| Navigation till sektioner              | Fyra navigationslänkar och länkar till respektive programpunkt     |
| HTML, semantik och bilder              | Ett h1, konsekvent h2/h3, landmärken, alt-text och bilddimensioner |
| Tangentbord                            | Egen `:focus-visible`, tabbordning, Escape i mobilmeny             |
| Zoom                                   | Verklig 200%/300% webbläsarzoom med separat resultatfil            |
| Dokumentation och AI-process           | README, Prettier-konfiguration och verifieringsunderlag            |
| Publicering                            | GitHub-repo och GitHub Pages med automatiskt bygge och tester      |

Den individuella redovisningen och kunskapsfrågorna bedöms av läraren. Git-historik och
övriga betygskriterier bedöms separat från de tekniska kontrollerna ovan.
